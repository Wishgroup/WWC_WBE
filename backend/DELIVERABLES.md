# Backend Enhancement – Files Created/Modified

Production-ready and portfolio-safe enhancements. **Database: MySQL** (not MongoDB).

---

## Created

### Config & utils
- **config/index.js** – Env-based config (server, db, jwt, rateLimit, frontend, admin).
- **utils/response.js** – Consistent API responses: success, paginated, error, notFound.
- **utils/pagination.js** – getPagination(), getLimitOffset() for list endpoints.

### Validations
- **validations/nfc.js** – Zod schema and validateNfcTapBody() for POST /api/nfc/validate.
- **validations/common.js** – paginationSchema, idParamSchema, emailSchema, passwordSchema, validate().

### Middleware
- **middleware/errorHandler.js** – Central error handler; consistent JSON; logs 5xx to audit.
- **middleware/requestLogger.js** – Winston logger + HTTP request log (method, url, status, ms).

### Scripts
- **scripts/add-indexes.js** – Composite indexes for nfc_tap_logs (member+time, vendor+time), audit_logs (created_at).

### Analytics (portfolio-safe, no real data)
- **analytics/README.md** – Overview and run instructions.
- **analytics/synthetic_data_generator.js** – Generates synthetic_scans.json, synthetic_fraud_events.json.
- **analytics/transaction_kpi_analysis.py** – KPIs (scans/day/week/month, unique members, top vendors, success rate, latency); outputs kpi_summary.json, kpi_results.png.
- **analytics/fraud_rule_analysis.py** – Counts per fraud rule type; outputs fraud_rule_summary.json.
- **analytics/system_metrics.md** – Documents KPIs and data sources.
- **analytics/output/** – Generated by scripts (synthetic_scans.json, synthetic_fraud_events.json, kpi_summary.json, etc.).

### Docs
- **docs/api.md** – Auth, NFC validation, admin, payment, health with request/response examples.

## Modified

- **package.json** – Added dependencies: `zod`, `morgan`; no script changes.
- **server.js** – Uses config, requestLogger, errorHandler; 404 and final error handler use consistent format.
- **routes/nfc.js** – Zod validation (validateNfcTapBody), latency logging (validation_latency_ms in audit), error rethrow for central handler.
- **.env.example** – Added HOST, LOG_LEVEL, JWT_EXPIRES_IN.
- **README.md** – Replaced with overview, architecture (ASCII), features, tech stack (MySQL), env vars, run locally, security, API summary, analytics overview, project structure.

## Run

```bash
npm install
cp .env.example .env   # edit DB and secrets
npm run migrate
npm run dev
```

Optional: `node scripts/add-indexes.js`  
Analytics: `node analytics/synthetic_data_generator.js` then run Python scripts (see analytics/README.md).
